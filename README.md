# 植物大战僵尸小游戏

一个纯前端实现的简化版植物大战僵尸，包含闯关系统、阳光经济、三种植物与多种僵尸。打开 `index.html` 即可游玩。

## 运行方式

1. 在本地双击 `index.html`，或使用任意静态服务器：
   ```bash
   python -m http.server 8000
   ```
   然后访问 `http://localhost:8000`。
2. 首次进入会自动开始第 1 关，点击植物卡片后再点击草坪即可种植。
3. 收集掉落的阳光，阻止僵尸进入左侧，通关后可进入下一关。

## 功能亮点
- 3 个关卡递进难度，不同僵尸组合。
- 阳光掉落 + 向日葵产阳光的经济体系。
- 豌豆射手远程输出、坚果墙高血量防御、向日葵经济。
- 进度条展示当前波次推进。
- 快捷键：`1/2/3` 选植物，空格取消，`R` 重开本关。
